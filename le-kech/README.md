# Le Kech – Restaurangwebbplats

## Om projektet
Le Kech är ett enkelt webbprojekt där målet är att skapa en webbplats för en restaurang. Projektet börjar med en designskiss i Figma och fortsätter med att utveckla en fungerande webbplats med HTML, CSS och JavaScript.

## Syfte och mål
Syftet med projektet är att omvandla en designidé till en fungerande och användarvänlig webbplats. Fokus ligger på design, struktur, funktionalitet och användarupplevelse.

## Designprocess
Arbetet börjar med att skapa en designskiss i Figma. Skissen används sedan som grund för att bygga webbplatsen. Designen hjälper till att bestämma webbplatsens layout, färger, typografi och visuella uttryck.

## Tekniker och verktyg
- Figma – för design och planering av webbplatsen
- HTML5 – för webbplatsens struktur
- CSS3 – för utseende, layout och responsiv design
- JavaScript – för interaktivitet och funktionalitet
- Visual Studio Code – för att skriva och organisera koden

## Funktioner
Webbplatsen utvecklas med målet att innehålla:
- En tydlig och tilltalande design
- En användarvänlig struktur och navigering
- En layout som fungerar på olika skärmstorlekar
- Interaktiva funktioner med JavaScript

## Arbetsprocess
1. Skapa en designskiss i Figma.
2. Planera och organisera projektets filer.
3. Bygga webbplatsens struktur med HTML.
4. Utforma webbplatsen med CSS.
5. Lägga till interaktiva funktioner med JavaScript.
6. Testa och förbättra webbplatsens design och funktionalitet.

## Hur man startar projektet
1. Öppna projektmappen i Visual Studio Code.
2. Starta webbplatsen med  tillägget Live Server.
3. Öppna webbplatsen i webbläsaren och testa dess funktioner.

## Projektstatus
Projektet utvecklas stegvis från designskiss till en fungerande webbplats.
